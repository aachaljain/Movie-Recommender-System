<h1>🎬 Movie Recommender System</h1>

<p>
A content-based movie recommendation system built using <b>Natural Language Processing (NLP)</b> techniques.
The application recommends movies similar to a selected movie by analyzing movie metadata and computing similarity scores using <b>TF-IDF Vectorization</b> and <b>Cosine Similarity</b>.
</p>

<h2>🚀 Features</h2>

<ul>
    <li>Content-Based Movie Recommendation</li>
    <li>NLP-based Movie Similarity Analysis</li>
    <li>TF-IDF Vectorization</li>
    <li>Cosine Similarity Matching</li>
    <li>FastAPI Backend</li>
    <li>Streamlit Frontend</li>
    <li>Fast and Lightweight Recommendations</li>
    <li>Preprocessed and Serialized Model Files using Pickle</li>
</ul>

<h2>⚙️ How It Works</h2>

<ol>
    <li>Movie metadata such as genres, keywords, cast, crew, and overview are combined into a single text feature.</li>
    <li>Text data is preprocessed and transformed using TF-IDF Vectorization.</li>
    <li>Cosine Similarity is calculated between movie vectors.</li>
    <li>The system identifies and recommends the most similar movies based on similarity scores.</li>
</ol>
