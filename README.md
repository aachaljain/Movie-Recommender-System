<h1>🎬 Movie Recommender System</h1>

A content-based movie recommendation system built using Natural Language Processing (NLP) techniques. The application recommends movies similar to a selected movie by analyzing movie metadata and computing similarity scores using TF-IDF Vectorization and Cosine Similarity.

🚀 Features
Content-Based Movie Recommendation
NLP-based movie similarity analysis
TF-IDF Vectorization
Cosine Similarity Matching
FastAPI Backend
Streamlit Frontend
Fast and lightweight recommendations
Preprocessed and serialized model files using Pickle
